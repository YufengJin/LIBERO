# LIBERO — Install Recipe

Minimum commands to reproduce this container from a fresh clone. Generated by `env-generator` skill.

## Host prerequisites

- Docker (>= 24) and the Compose v2 plugin
- NVIDIA driver >= 450 and the NVIDIA Container Toolkit
- A GPU visible to `nvidia-smi`

Run the bundled check before building:

```bash
bash docker/check_prereqs.sh
```

## Build the image

```bash
docker compose -f docker/docker-compose.headless.yaml build
```

Base image: `nvidia/cuda:11.8.0-cudnn8-runtime-ubuntu20.04`
Python: `3.8` (managed by `uv` in `/opt/venv`)
Install strategy: `uv sync --frozen --no-install-project --active`

## Bring the container up

```bash
docker compose -f docker/docker-compose.headless.yaml up -d
docker exec -it libero-headless bash
```

For an X11-enabled session (GUI apps, visualisers):

```bash
xhost +local:docker
docker compose -f docker/docker-compose.x11.yaml up -d
```

Only one of the two profiles may run at a time — they share the container name.

## First-run sanity checks (inside the container)

```bash
nvidia-smi
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
python -c "import libero; print(libero.__file__)"
```

The last line must resolve under `/workspace/LIBERO/` — this proves that the mounted source is the one the interpreter imports (editable install succeeded).

## LIBERO config path

The entrypoint auto-creates `/workspace/.libero/config.yaml` and the compose file sets `LIBERO_CONFIG_PATH=/workspace/.libero`. This bypasses the interactive prompt that `import libero.libero` would otherwise trigger on first run. No manual action is needed.

## Optional dataset download

Datasets are only required for training or evaluating trained policies. Inside the container:

```bash
python benchmark_scripts/download_libero_datasets.py --use-huggingface
```

## Stop / clean up

```bash
docker compose -f docker/docker-compose.headless.yaml down
```
