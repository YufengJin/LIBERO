### Known limitations

- `scripts/run_eval.py` always iterates every task in the selected suite (`for task_id in range(num_tasks)`). For `libero_90` that is 90 tasks — a 1-trial smoke run on that suite would exceed the L3_IL 90 s budget. If you need a single-task eval, use `run_demo.py` (supports `--task_id`) or extend `run_eval.py` with a `--task_ids` filter.
- `[robosuite WARNING] No private macro file found!` is printed on every env construction. It is harmless (robosuite falls back to internal defaults). Optional fix: run `python /opt/venv/lib/python3.8/site-packages/robosuite/scripts/setup_macros.py` once and rebuild.
- `Gym has been unmaintained since 2022` warning is unavoidable — `gym==0.25.2` is pinned because `robosuite 1.4.0` + LIBERO's lifelong package still import `gym`, not `gymnasium`. Cosmetic only.
- Datasets are NOT downloaded by default; the entrypoint warns and points at `benchmark_scripts/download_libero_datasets.py --use-huggingface`. BC training / demo evaluation needs them; the smoke test does not.
