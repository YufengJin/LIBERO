### Known limitations

- **Sparse reward only** — env returns `0.0` every step and `1.0` only on success. RL training is impractical here; this benchmark is for IL/lifelong-IL exclusively.
- **Datasets not auto-downloaded** — `[Warning]: datasets path /workspace/libero/datasets does not exist!` is harmless for the random-policy smoke loop but real BC training requires `python benchmark_scripts/download_libero_datasets.py --use-huggingface` (~10–20 GB).
- **Default `policy_server_addr` is `localhost:8000`** in `scripts/run_demo.py` and `scripts/run_eval.py` (verified-fork legacy). The smoke harness used `8765` (the `policy_websocket` library default); pass `--policy_server_addr` explicitly when standing up your own server.
- **`__meta__` envelope absent** — verified-fork scripts use a flat `task_description` key in the obs payload instead of the standard nested `obs["__meta__"]` envelope. Downstream policy-generator targets that need the canonical envelope must adapt the policy server, not the client.
- **Cross-controller spec consistency unverified** — the captured spec is only for OSC_POSE (7-D). The 8-D `joint_vel` / DROID-style controller would expose a different `action_spec.shape` and different proprio dims; re-run `capture_spec.py` with `controller='JOINT_VELOCITY'` if you need that variant in the registry.
